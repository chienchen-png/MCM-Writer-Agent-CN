# LaTeX 模板目录说明

> 📂 本目录包含 CUMCM 官方 LaTeX 模板（`cumcmthesis`）及你的论文源文件。
> 下面用中文说明每个文件是干什么的，方便快速定位。

---

## 📄 核心文件

| 文件 | 中文名称 | 说明 |
|------|---------|------|
| `example.tex` | **这是 LaTeX 核心代码** | 论文的入口文件。所有章节内容写在这里。用 XeLaTeX 编译它即可生成论文 PDF。`example(1).tex` 是你的实际工作副本。 |
| `cumcmthesis.cls` | **这是模板格式定义文件** | 定义了封面、字号、字体、页边距等全部格式。`cumcmthesis(1).cls` 是工作副本。**一般不需要改动它。** |
| `example.pdf` | **这是最终渲染生成的 PDF 文件** | `example.tex` 编译后输出。双击即可查看论文效果。`example(1).pdf` 是工作副本。 |

---

## 🖼️ 图片文件夹

| 文件夹 | 中文名称 | 说明 |
|------|---------|------|
| `figures/` | **这是图片存放处** | 把你论文中要用的图片（`.pdf` `.png` `.jpg`）放到这里，然后在 .tex 中通过 `\includegraphics{文件名}` 引用。**图片名禁用中文** |

---

## 🗑️ 辅助/临时文件

| 文件类型 | 说明 |
|---------|------|
| `*.aux` | 交叉引用辅助文件，编译时自动生成 |
| `*.log` | 编译日志，**语法报错时看这个文件找原因** |
| `*.out` | 超链接/书签辅助文件 |
| `*.toc` | 目录辅助文件 |
| `*.synctex.gz` | 正反向搜索辅助文件 |
| `*.bbl` / `*.bcf` / `*.blg` | 参考文献编译辅助文件 |
| `.gitignore` | Git 忽略规则，自动排除上述临时文件 |
