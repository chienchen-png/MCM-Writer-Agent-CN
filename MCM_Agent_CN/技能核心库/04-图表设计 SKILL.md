## 核心指令

### 步骤 1：读取输入
1. 读取要配图的建模文档（`当前赛题/建模思路/QX_建模思路文档.md`）。
2. 读取对应的运行结果（`当前赛题/编程计算结果/QX_运行结果.md`）。
3. 读取 `知识库/模板与规范/图表模板与撞色配色设计.md`（配色规范）。
4. 读取 `当前赛题/论文草稿/论文大纲_草稿.md`（确认图表清单）。

### 步骤 2：数据分析

从建模文档和运行结果中提取：
- 适合可视化的数据列（如时间序列、分类对比数据、收敛数据）
- 需要展示的逻辑流程（如算法步骤、决策路径）
- 需要对比的维度（如不同方案的指标对比）

### 步骤 3：生成图表设计方案

对每个建议的图表，输出以下完整方案：

```markdown

| 属性 | 值 |
|------|-----|
| **图表类型** | 折线图 / 柱状图 / 热力图 / 流程图 / 箱线图 / 散点图 |
| **配色方案** | 方案A（学术蓝-橙）/ 方案B（暖色对比）/ 方案C（冷色专业） |

| **引用语句** | "参见图X-Y所示的XX曲线" |
| **生成方式** | Python(matplotlib) / diagram_utils / Mermaid→PNG |
```

## 图表类型决策树

```
数据类型判断：
├── 是算法流程/决策逻辑？
│   └── 流程图（diagram_utils.flowchart / Mermaid）
├── 是随时间变化的序列？
│   └── 折线图（多系列叠加）
├── 是不同方案/算法的对比？
│   ├── 指标数量 ≤ 3 → 分组柱状图
│   ├── 指标数量 > 3 → 雷达图
│   └── 多次实验结果 → 箱线图
├── 是变量间关系？
│   ├── 2个变量 → 散点图 + 拟合线
│   └── 多个变量 → 热力图（相关性矩阵）
├── 是比例/构成？
│   ├── 类别 ≤ 5 → 饼图
│   └── 类别 > 5 或多维 → 堆叠柱状图
└── 是模型结构？
    └── 关系图/概念模型图（diagram_utils.relationship_diagram）
```
