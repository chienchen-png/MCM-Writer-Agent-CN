# 03-论文写作 SKILL

## 触发条件

当用户指令包含以下关键词时激活：
- "写第X问"（X=1/2/3/4）
- "撰写XX部分" / "撰写XX章节"
- "写摘要" / "写问题重述" / "写模型假设" 等具体章节名
- "继续写作" / "补充内容"

## 前置条件检查

执行前必须确认：
1. `当前赛题/论文草稿/论文大纲_草稿.md` 已存在
2. 对应问题的 `建模思路文档` 已存在
3. 对应问题的 `编程计算结果` 已存在

若不存在，提示用户先完成前置步骤。

## 核心指令

### 步骤 0：写作前准备
1. 读取 `当前赛题/赛题原文/问题陈述.md`，理解题干背景与各问题之间的逻辑关系。
2. 读取 `当前赛题/论文草稿/论文大纲_草稿.md`，确认当前写作位置。
3. 读取对应的 `知识库/模板与规范/范文模板/{A,B,C}题.md` 中该章节的写作技巧。
4. 读取对应的 `当前赛题/建模思路/QX_建模思路文档.md`。
5. 读取对应的 `当前赛题/编程计算结果/QX_运行结果.md`。
6. 读取 `知识库/模板与规范/图标模板/图表模板与撞色配色设计.md`（配色参考）。

### 步骤 1：图表处理

在正式写作前，检查本章节所需的图表是否已存在。

#### 图表处理规则

```
检查 论文草稿/图表/ 目录：
├── 图表 PNG/drawio 文件已存在？
│   └── ✅ 直接插入引用："如图X-Y所示"，配合图片路径
│
└── 图表文件不存在？
    └── 📝 使用【图表占位】标注，交由团队建模手后续绘制
       格式：【图表占位：图X-Y | 图表类型 | 内容描述 | 配色建议】
       示例：【图表占位：图3-1 | 流程图 | 遗传算法求解排产问题的流程步骤 | draw.io】
       示例：【图表占位：图3-2 | 折线图 | 方案一/二/三的收敛曲线对比 | 方案A配色】
```

> ⚠️ **职责边界**：Agent 负责文字写作，团队建模手负责图表绘制。Agent 不在此阶段自动触发 04-Skill 绘制图表，以防止 token 浪费。如需绘图，用户可明确说"画图"触发 04-Skill 的绘制模式。

### 步骤 1.5：文献引用决策与检索

在正式写作前，根据范本章节的引用规范和当前章节内容，决定是否需要引入引用文献。

#### 引用决策流程

```
当前章节 → 读取范文模板「五、文献引用规范」→ 该位置是否通常有引用？
                                                          │
                              ┌───────────────────────────┤
                              ▼                           ▼
                           需要引用                      不需要引用
                              │                           │
                              ▼                           ▼
                  确定引用类型（背景/方法/对比）      跳过，直接写作
                              │
                              ▼
                  从章节内容提取关键词 → 构造 CNKI 检索词
                              │
                              ▼
                  调用 mcp_cnki_cnki_search → 筛选相关文献
                              │
                              ▼
                  选择 1-2 篇最相关文献 → 按范文引用格式插入
```

#### CNKI 搜索执行规范

```
# 搜索词构造规则
- 从当前章节的模型名称、算法名称中提取核心词
- 结合赛题领域关键词（从赛题原文中提取）
- 使用中文关键词优先，必要时配合英文
- 示例：
  - 写"遗传算法求解排产问题" → search query: "遗传算法 生产排产 优化"
  - 写"多目标规划" → search query: "多目标优化 工厂调度"
  - 写"灵敏度分析" → search query: "灵敏度分析 鲁棒性 优化"

# 调用参数
- db_code: "CJFD"（期刊论文）
- year_start: 当前年份 - 10
- year_end: 当前年份
- max_results: 5
```

#### 引用插入格式

引用格式严格遵循范文模板中的风格：
- 上标格式：`[1]`, `[2-4]`
- 典型句式：
  - "文献[1]提出了基于...的优化方法"
  - "借鉴文献[2]中...的思想，本文..."
  - "与文献[3]的研究结论一致，..."

#### 引用核查清单

写入引用后自查：
1. ✅ 引用文献来自 CNKI 真实搜索结果
2. ✅ 引用数量符合范文模板中该章节的正常范围
3. ✅ 未虚构任何参考文献
4. ✅ 所有引用已同步添加至 `论文草稿/分章节/11_参考文献.md`

### 步骤 2：分段写作

严格按以下原则写作：

#### 写作原则（不可违反）

1. **不编造数据**：所有表格数据必须从 `编程计算结果` 文件中直接引用。如数据缺失，使用 `【占位_描述性说明】` 标注。
2. **公式规范**：
   - 所有公式使用 LaTeX 语法：`$$ ... $$`（独立公式）或 `$ ... $`（行内公式）
   - 变量符号必须与建模思路文档中的符号**严格一致**
   - 每个公式应有编号：`\tag{1}`、`\tag{2}` 等
3. **图表引用**：
   - 已有图表 → 使用 Markdown 图片语法插入：`![图X-Y](图表/图X-Y.png)`，配合引用语句"如图X-Y所示"
   - 缺失图表 → 使用占位符：`【图表占位：图X-Y | 类型 | 描述】`，提醒团队建模手后续绘制
4. **参考范文模板**：模仿范文的语言风格、详略安排、段落衔接方式。
6. **引用规范**：引用文献须来自 CNKI 数据库真实检索结果，不得虚构参考文献；引用位置和数量需参考范文模板中对应获奖等级的引用分布模式；每处引用必须有对应的参考文献条目。
7. **占位符规则**：暂时无法确定的数值、图表，一律使用占位符标注。图表占位符格式：
   - `【图表占位：图X-Y | 图表类型 | 内容描述 | 配色建议】`
   - 示例：`【图表占位：图3-1 | 流程图 | 遗传算法求解排产问题的步骤流程 | draw.io】`
   - 示例：`【图表占位：图3-2 | 折线图 | 方案一/二/三的收敛曲线对比 X轴=迭代次数 Y轴=目标函数值 | 方案A配色】`
   - 示例：`【数值占位：具体数值 需编程确认】`

#### 各章节写作指引

##### 摘要（最后写）
- 一句话背景引入
- 逐问说明：方法 + 核心结论（1-2句/问）
- 总体结论
- 关键词 4-6 个

##### 问题重述
- 用自己的语言重新组织，不照抄原文
- 突出核心约束和目标
- 建立数学化的表述框架

##### 模型假设与符号说明
- 假设列表（5-8 条），每条有简要理由
- 符号表使用三线表：`| 符号 | 含义 | 单位 |`

##### 模型建立与求解（核心）
- 每问独立成节
- 结构：决策变量 → 目标函数 → 约束条件 → 求解算法 → 结果分析
- 公式推导逐步展开，关键步骤不跳跃
- 结果用表格呈现，配合分析文字

##### 灵敏度分析
- 对关键参数做 ±10% / ±20% 扰动
- 分析目标函数的变化趋势
- 给出模型鲁棒性结论

##### 模型评价与推广
- 优点：3-4 条，结合具体模型特点
- 缺点：2-3 条，诚实但不过度贬低
- 推广方向：2-3 个实际应用场景

## 学术写作风格参考

### 推荐句式
- "本文构建了...模型，以...为目标函数，以...为约束条件。"
- "由表X-Y可知，当参数 α 从 0.5 增加到 0.8 时，目标函数值降低了 12.3%。"
- "对比方案一与方案二可以发现，...方案在...方面具有显著优势。"
- "为进一步验证模型的可靠性，本节对关键参数进行了灵敏度分析。"

### 禁用表达
- ❌ "我们"（用"本文"替代）
- ❌ "我觉得"、"我认为"（用"分析表明"、"结果表明"）
- ❌ 口语化表达如"搞定了"、"差不多"
- ❌ 直接复制题干原文（问题重述除外）

## 错误处理

- 若建模文档与编程结果中的变量名不一致，暂停并提示用户确认。
- 若大纲要求的图表在图表目录中不存在，标注占位符并继续。
- 若数据表格过于复杂（超过 10 列），建议拆分为多个小表。
