# 05-论文评审 SKILL

## 触发条件

当用户指令包含以下关键词时激活：
- "检查论文" / "检查初稿" / "论文质检"
- "模拟评审" / "模拟评委打分"
- "打分" / "评分"
- "评审"

## 核心指令

本 Skill 采用**双模式**运行：

### 模式一：质检模式（格式规范检查）

自动执行，扫描技术性错误。

#### 检查项清单

##### 1. 公式编号连续性
- 扫描 `论文草稿/分章节/` 中所有 `\tag{}` 编号
- 检查是否存在跳号、重复编号
- 报告格式：
  ```
  ✅ 公式编号检查：共 N 个公式，编号从 (1) 到 (N)，连续无跳号。
  ❌ 公式编号检查：缺少编号 (5)，(7) 重复出现 2 次。
  ```

##### 2. 图表编号完整性
- 扫描正文中的图表引用（如图X-Y、表X-Y）
- 对比 `论文草稿/图表/` 目录下的实际图表文件
- 检查是否有引用但无文件 / 有文件但未引用
- 报告格式：
  ```
  ✅ 图表引用检查：共引用 M 张图，全部对应文件存在。
  ❌ 图表引用检查：图3-2 被引用但文件缺失；图4-1.md 存在但未在正文引用。
  ```

##### 3. 数据来源追溯
- 提取正文中所有表格数据
- 与 `当前赛题/编程计算结果/` 对照
- 标记数据不一致项
- 报告格式：
  ```
  ✅ 数据追溯检查：所有表格数据与编程结果一致。
  ❌ 数据追溯检查：表3-1 第三行总成本 123.5 与运行结果 125.3 不一致。
  ```

##### 4. 符号一致性检查
- 提取正文中所有数学符号
- 与 `建模思路/` 文档中的符号对照
- 检查是否出现未定义符号或符号冲突
- 报告格式：
  ```
  ✅ 符号一致性检查：所有符号与建模文档一致。
  ❌ 符号一致性检查：变量 τ 在正文中使用但未在符号表中定义。
  ```

##### 5. 参考文献格式检查
- 检查参考文献编号是否按引用顺序排列
- 检查正文引用是否都有对应参考文献
- 报告格式：
  ```
  ✅ 参考文献检查：共 N 条，格式规范。
  ❌ 参考文献检查：正文引用 [5] 在参考文献列表中缺失。
  ```

##### 6. 文献引用质量检查
- **来源可追溯性**：扫描所有参考文献，逐一尝试通过 CNKI 检索确认其真实存在
- **引用格式一致性**：检查所有引用是否使用统一的 `[N]` 上标格式
- **文献类型多样性**：统计中文期刊/英文/学位论文/教材比例，与范文模板预期对比
- **引用位置合理性**：统计各章节引用密度，与范文模板「五、文献引用规范」中 5.3 节引用位置规律对比
- **引用充分性**：引用总量是否达到范文模板中对应获奖等级的预期范围
- 报告格式：
  ```
  ✅ 文献引用检查：共 N 条引用，来源全部可追溯，类型分布合理。
  ❌ 文献引用检查：
    - [3] 无法在 CNKI 中检索到（疑似虚构）
    - 英文文献占比 80%，偏离范文 A 题常见模式（20-40%）
    - 模型建立章节引用数 0，范文同级论文中位数为 4
    - 引用格式不统一：[1] 和 (2) 两种风格混用
  ```

##### 7. 占位符检查
- 扫描全文中的 `【占位_` 标记
- 列出所有未填补的占位符
- 报告格式：
  ```
  ⚠️ 占位符提醒：共发现 3 处占位符待填补：
  - 【占位_灵敏度分析图】（第9章）
  - 【占位_模型对比表】（第6章）
  - 【占位_具体数值_需编程确认】（第5章）
  ```

### 模式二：评委模式（模拟国赛评分）

加载 `知识库/模板与规范/国赛评分细则.md`，扮演犀利评阅专家。

#### 评分流程

1. 通读全文（`论文草稿/分章节/` 下所有文件）
2. 依据 11 个评分维度逐项打分
3. 汇总总分，判定获奖等级
4. 提出改进建议

   评审时间：YYYY-MM-DD
   评审模式：质检 + 评委双模式

### 步骤 4：记录评审意见

```markdown
| 序号 | 日期 | 赛题 | 评审模式 | 总分 | 等级 | 关键问题 | 改进建议 |
|------|------|------|---------|------|------|---------|---------|

```

### 步骤 5：更新日志

评审完成后，更新当前赛题的 `进度日志.md`。

## 评审专家角色设定

在评委模式下，你必须扮演以下角色：

> 你是全国大学生数学建模竞赛的资深评阅专家，拥有 15 年以上评审经验。
> 你以严格著称，对模型的逻辑自洽性有近乎苛刻的要求。
> 你特别关注：
> - 模型假设是否合理可解释
> - 数学推导是否严谨
> - 数据是否真实可信
> - 结论是否有充分支撑
> 你不会给出"不错"、"较好"等模糊评价，必须给出具体的问题定位和改进方向。

| 图表文件 | `当前赛题/论文草稿/图表/*.md` | ✅ |

## 输出规范

| 输出项 | 路径 | 说明 |
|--------|------|------|
| 评审报告 | 对话输出 | 按格式输出完整评审报告 |
| 评审记录 | `知识库/评委记忆/历史评审意见库.md` | 追加记录 |

## 错误处理

- 若论文草稿目录为空，输出："论文草稿为空，请先完成写作。"
- 若部分章节缺失（如缺少灵敏度分析），在评分中标注并扣除对应维度分数。
- 若图表目录为空，在质检报告中标注"图表全部缺失"。
