# B题范文模板

> 模板说明：本文件通过 "01-文献阅读与整理" Skill 自动生成和更新，用于存储 B 题（离散型/组合优化类）范文的写作风格、结构和句式总结。
> 最近更新：2026-07-19，基于 3 篇 B 题国赛范文。

## 一、常见题型特征

B 题通常为**离散型优化**或**组合优化**问题，典型特征：
- 以**无人机编队、路径规划、资源调度、网络优化**等为背景
- 涉及**几何建模**（极坐标、正弦定理、计算几何）与**搜索/迭代算法**（遍历、贪心、启发式搜索、仿真模拟）
- 问题通常**4 问递进**：基础定位 → 扩展条件 → 调整方案 → 推广验证
- 偏重**算法设计**与**数值计算**，公式推导以几何关系为主
- 答案常以**坐标表、收敛曲线、调整步骤表**等形式呈现

本模板基于 3 篇 B 题范文提取：
| 范文 | 核心方法 | 获奖等级（推定） |
|------|---------|----------------|
| 1.md — 无人机遂行编队飞行中的纯方位无源定位 | 正弦定理几何建模 + 遍历/迭代 | 国二及以上 |
| 2.md — 基于计算几何与带阈值启发式搜索的无人机无源定位模型 | 计算几何两圆求交 + IDA*启发式搜索 | 国一 |
| 3.md — 基于局部最优模型的无人机位置调整策略与仿真定位 | 局部最优模型 + 贪心 + 仿真 + 三维平面拟合 | 国一 |

## 二、论文结构模板

### 题目

#### 【通用】题目命名规范（学校素材）

**两类命题思路（老师爬虫统计近3年国奖）：**

**【阵营一】"基于"类（约30%）** —— 不建议

- 基于价格弹性的蔬菜类商品自动定价与补货决策（23国赛C题）
- 基于主要目标法的测线设计问题（24国赛B题）
- 基于成分数据的古代玻璃制品的成分分析与鉴别（22国赛C题）

**【阵营二】题目即标题（约70%）** —— 推荐

- 某商超蔬菜类商品动态定价与补货决策研究（23国赛C题）
- 多波束测深合理探测方案的设计及效果分析（24国赛B题）
- 定日镜场的输出功率优化（23国赛A题）

**为什么不推荐"基于"类：**

1. 国赛综合性高，常需多个模型，学生易"造词"堆砌算法名（模拟退火/遗传算法/随机森林），老师反感"标题党"与"八股文"。
2. 大多赛事明文规定禁止自拟题目（如深圳杯），渐成"潜规则"。
3. 老师喜欢**务实低调**，说清论文任务主题即可。

**B 题命名建议**：直接点明[研究对象 + 策略/方案]，如"XX的XX方案设计"。

---

**本题特化（B 题范文示例）**：

- 《基于计算几何与带阈值启发式搜索的无人机无源定位模型》
- 《基于局部最优模型的无人机位置调整策略与仿真定位》
- 《无人机遂行编队飞行中的纯方位无源定位》

> 💡 标题规律：直接点明核心算法/模型，不拐弯抹角。

### 摘要

#### 【通用】摘要写作核心规范（学校素材）

**逻辑原则（铁律）**：遇到什么问题 → 使用什么方法 → 得到什么结果。

**结构：总分总**（开头总起 → 逐问分述 → 结尾总结）

**注意：**

- 分段、分问题（每段开头"针对问题X"）
- 每段约 5 行
- 有标准答案的结果加粗、重点模型加粗、重点发现加粗

**误区（做减法，别做加法）：**

1. 摘要不是"选秀"，切忌大面积加粗，一个问题最多 3 个模型，过犹不及。
2. 写摘要是"做减法"，切忌臃肿。
3. 时刻想好小说六要素（背景/问题/方法/过程/结果/意义），减法的同时不漏点。
4. 避免主观评价，不要跳逻辑。

**B 题摘要特点**：每问必答，明确对应"问题一(1)""问题一(2)"等标签；使用"首先…再…最后…"递进结构；关键词排列与问题解决顺序一致。

---

**本题摘要样板（逐字摘取 `文献库/B题/1.md`，作为照抄范例）：**

> 本文主要研究无人机纯方位无源定位，建立定位模型和调整方案模型完成有效定位被动接收信号无人机以及进行纯方位无源定位调整工作。
>
> 针对问题一（1），首先根据3架无人机相对位置信息进行分类讨论，再结合正弦定理以及其他几何关系，确定六种定位模型，采用遍历算法，固定一架发射信号无人机，遍历另外两架无人机的相对位置关系，求解每种情况下所有位置上被动接收无人机的实际坐标，输出图解结果，发现定位效果良好，模型合理。
>
> 针对问题一(2)，在无人机知道自身编号与其余无人机的相对位置关系的假设条件下，确定位置编号发射信号无人机的相对位置，再推断其准确标号。随后结合问题一（1）定位模型计算被动接受无人机坐标，确定定位是否有效。利用仿真模拟生成的无人机实际坐标样本，验证得仅需通过增加一架无人机发射信号就能够有效定位接受信号无人机位置。
>
> 针对问题一（3），分析给定初始坐标值，调整方案分为三步骤，步骤一：利用问题一（1）的定位模型，调整同一圆周上的三架无人机的相对位置接近理想位置关系。步骤二：以步骤一中三架无人机为参照系，利用问题一（1）的定位模型，调节余下无人机的角度坐标，使之接近理想相对位置，输出角度调节量：步骤三：同步骤二参照基准，建立几何关系模型，调节余下无人机的长度坐标。每一步骤都对应各自独立的调整模型，模型求解利用迭代算法进行。通过输出调整后的坐标位置信息，对比初始位置信息确认此方案模型可行、实用。
>
> 针对问题二，将锥形编队分解成多个同心圆的圆形编队，利用问题一（3)中给出的调节方案调整各圆周上无人机，针对特殊点通过共线无人机制定相应的调整方案。
>
> 关键词：遍历算法、定位模型、调整方案模型、迭代算法、仿真模拟

### 问题重述

#### 【通用】问题重述写法（学校素材）

- **标准结构**：`1.1 问题背景` + `1.2 问题重述/问题提出`。
- **背景段**（1-2段）：用自己的语言引入研究对象，带出核心矛盾，可引用 1-2 篇文献增强可信度。
- **重述段**：将题干各问整理为（1）（2）（3）…，突出核心要求与关键给定数据，**不照抄原题**，加入理解性概括。
- 可用一句总领："问题设置层层递进，服务于同一主题——……"。

---
- **背景段**（1-2 段）：从实际应用引出，可用 `[1]`、`[2]` 引用支撑。例如：
  > "考虑到传统有源雷达不适用于城市复杂电磁环境……无源定位技术成为对无人机定位的首选。[4]"
- **问题重述**：用自己的语言重新组织，按问分条，包含题目给定的关键数据（编队规模、编号规则、约束条件）。
- **不照抄原题**，而是加入理解性概括。

### 模型假设

#### 【通用】模型假设与符号说明写法（学校素材）

- **假设 5-8 条**，每条一句话，聚焦理想化条件（忽略次要因素、参数恒定、近似质点化、特定条件成立）。
- **符号表用三线表** `| 符号 | 含义 | 单位 |`。
- 符号集中在模型建立前统一声明，末尾可加"其他符号将在下文中给出"。

---
**数量**：3-7 条（范文分别为 3 条、5 条、7 条）

**常见假设清单**：

| 假设 | 出现频率 | 来源 |
|------|---------|------|
| 无人机发射/接收信号稳定不受干扰 | 3/3 | 三篇均含 |
| 忽略信号处理时间 | 1/3 | 仅1.md |
| 每架无人机知道自身编号及相对位置关系 | 2/3 | 1.md, 3.md |
| 位置偏差是小量（角度 ±1°~±5°，极径 ±15%） | 3/3 | 核心假设 |
| 无人机能沿任意方向移动（或有限制） | 2/3 | 2.md, 3.md |
| 地面掌握无人机位置信息并可发送指令 | 1/3 | 2.md |
| 无人机按计算矢量精确移动，无机械误差 | 1/3 | 2.md |
| 无人机间信息不共享 | 1/3 | 3.md |
| 已知信号发射次序 | 1/3 | 3.md |

**写作风格**：简短陈述句，编号或项目符号列出，每条 1-2 行。

### 符号说明

**标准格式**：表格呈现（`| 符号 | 含义 |`）

- 符号集中在模型建立前统一声明
- 极坐标系统常用：$(\rho_i, \theta_i)$、$\alpha_{ij}$（方位角）
- 编号命名统一：FY0X 表示第 X 架无人机
- 末尾加注："其他符号将在下文中给出具体说明"

### 模型建立与求解

**这是 B 题论文的核心，占比 50%-60%。**

**分问结构**（最常见）：
```
五、问题一（1）模型的建立与求解
  5.1 [子模型名称]
  5.2 [求解过程]
六、问题一（2）模型的建立与求解
七、问题一（3）模型的建立与求解
八、问题二的模型建立与求解
```

**另一种结构**：
```
五、模型的建立与求解
  5.1 问题一 —— 三架无人机无源定位
    5.1.1 定位模型的建立
    5.1.2 模型求解
  5.2 问题二 —— 无源定位的无人机最小需求
  5.3 问题三 —— 圆周上无人机调整方案
    5.3.1 算法设计
    5.3.2 模型求解
    5.3.3 结论分析
```

**每问内部写作模板**：
1. **建模思路/推导**（30%）：从几何关系或数学原理出发，分类讨论
2. **公式推导**（40%）：逐步推导，关键步骤给出编号公式
3. **算法描述**（20%）：伪代码或步骤列表
4. **结果展示**（10%）：表格、图片呈现数值结果

**推导深度特征**：
- 分类讨论是 B 题标配（如3种相对位置关系 × 多种形态 → 6种定位模型）
- 先分类，再证明对称性可化简，最后给出统一公式
- 优先纯几何推导（正弦定理、向量叉积），减少依赖外部库

### 模型评价与推广

#### 【通用】模型评价与推广写法（学校素材）

**夸模型（分点，每点侧重点不同）：**

1. 【假设好】模型充分结合实际，简化了××条件，考虑了×重要因素，贴合实际，可推广到××；
2. 【参数好】模型运用××思想，抓住影响××的关键因素，将复杂问题转化为简单问题，合理设参，结果符合要求；
3. 【算法好】本文使用的××算法具有××、××等优点，对求解××模型非常适用；
4. 【结果好】本文得到的××（方案/策略）具有效率高、输出稳定、××均衡等特点，能有效提高××。

**不足与改进（较略，≥4行）：**

1. 【不够好】实际中××和××可能也是重要因素，本文未考虑，影响准确性；
2. 【适用范围窄】模型对现有条件效果好，对其他情形（如××）可能无法达到较好效果；
3. 【因素线性化】实际××影响可能非线性，本文作线性处理，忽略边际效应。

**推广/改进：**

- 推广：在××方面，可将××参数替换成××参数，解决××问题；
- 改进：结合参考文献××，进一步考虑××影响，得到更合理模型。

---
**B 题两种写作模式**：

- **模式一**（1.md、3.md）：`模型优点` → `模型缺点` → `模型推广`
- **模式二**（2.md）：`模型优点` → `模型缺点`（无单独推广节）

**优点常见表述**：
- "准确性高，误差小"
- "层次性高，由简入繁、层层递进"
- "普适性好，可推广到其他编队队形"
- "具有现实意义，程序可快速给出结果"
- "给出细致的误差分析，有较强的严谨性"

**缺点常见表述**：
- "假定前提存在一定严苛性"
- "仅考虑误差范围内的情况"
- "收敛速度较慢"（随机算法）
- "暴力搜索计算量大，与步长设置密切相关"

**推广方向**：
- "本文模型适用于所有圆形编队/锥形编队"
- "将无人机抽象为几何点，可沿用到宇宙飞船定位、船只定位等"

## 四、图表引用规范与风格

### 4.1 图表类型偏好

| 类型 | 用途 | 出现频率 |
|------|------|---------|
| 几何示意图 | 展示无人机相对位置、编队形状、角度关系 | ★★★★★（每篇 5-8 张） |
| 算法流程图/思路图 | 展示问题分析总体思路 | ★★★（1-2 张） |
| 结果数据表 | 展示坐标值、调整前后的对比 | ★★★★（3-5 张） |
| 收敛曲线图 | 展示误差随迭代次数的变化 | ★★（1-2 张） |

### 4.2 引用句式

- "如图X所示" / "如图X-X所示"（最常用）
- "（如图1-1所示）"（括号内引用）
- "图X中取……为……"（图中举例说明）
- "表X列出了……" / "如下表所示"
- "见式(1)-(2)" / "结果见式(1)-(2)"（公式引用）

### 4.3 图表配色风格

- 以**黑白线条图**为主（学术论文规范）
- 几何图中用标注文字区分无人机编号（FY00-FY09）
- 数据表用简洁三线表，无多余颜色
- 程序中可输出彩色图（用于调试），论文中以清晰黑白图呈现

### 4.4 编号规范

- 图编号：`图1-1`、`图1-2`（按章节编号）或 `图1`、`图2`（全文通排）
- 表编号：`表1`、`表2`（全文通排）或 `表 4`（含空格）
