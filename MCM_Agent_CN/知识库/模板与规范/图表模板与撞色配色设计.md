# 图表模板与撞色配色设计

> 本文档定义 MCM Agent 学术论文图表的设计规范，强调科研顶刊级别的撞色配色风格。

---

## 一、配色原则

### 1.1 撞色配色理念
- **高对比度**：确保黑白打印仍可辨识
- **色盲友好**：避免红绿搭配，优先选择蓝-橙、紫-黄配色
- **学术克制**：每张图主色不超过 4 种，避免过度花哨

### 1.2 推荐配色方案

#### 方案A：经典学术蓝-橙（默认推荐）
| 色号 | 名称 | 用途 |
|------|------|------|
| `#2B579A` | 学术蓝 | 主曲线/主柱 |
| `#E87722` | 警示橙 | 对比曲线/第二柱 |
| `#6B8E23` | 橄榄绿 | 辅助线/第三柱 |
| `#8B008B` | 深紫红 | 第四序列 |

#### 方案B：暖色系对比
| 色号 | 名称 | 用途 |
|------|------|------|
| `#C0392B` | 深红 | 主曲线 |
| `#2980B9` | 深蓝 | 对比曲线 |
| `#F39C12` | 金黄 | 高亮 |
| `#27AE60` | 翠绿 | 辅助 |

#### 方案C：冷色专业系
| 色号 | 名称 | 用途 |
|------|------|------|
| `#1A5276` | 深海蓝 | 主色 |
| `#117864` | 墨绿 | 对比色 |
| `#7D3C98` | 深紫 | 强调色 |
| `#B03A2E` | 暗红 | 警示色 |

### 1.3 背景与字体
- 图表背景：白色 `#FFFFFF`，无网格线或极淡灰网格
- 标题字体：SimHei（黑体），12-14pt
- 坐标轴标签：SimSun（宋体），10-11pt
- 图例：置于图内右上角或图下方，8-10pt

## 二、图表类型选择指南

| 数据类型 | 推荐图表类型 | 适用场景 |
|----------|-------------|---------|
| 时间序列 | 折线图 | 算法收敛、价格变化、温度监测 |
| 分类对比 | 分组柱状图 | 不同算法/方案效果对比 |
| 分布展示 | 箱线图/小提琴图 | 多次实验结果分布 |
| 相关性 | 热力图 | 变量间相关关系 |
| 比例构成 | 堆叠柱状图/饼图 | 成本构成、能耗占比 |
| 流程逻辑 | 流程图 | 算法流程、决策过程 |
| 空间关系 | 等值线图/散点图 | 污染物扩散、路径规划 |
| 综合评价 | 雷达图 | 多维指标对比 |

---

## 三、图表标注规范

### 3.1 编号规则
- 格式：`图X-Y` 或 `表X-Y`
- X = 问题编号（1/2/3/4）
- Y = 该问题内序号（从1开始）

### 3.2 标题格式
- 图标题置于图下方：`图3-2 遗传算法收敛曲线`
- 表标题置于表上方：`表2-1 各方案成本对比（单位：万元）`

### 3.3 引用句式模板
- "如图X-Y所示，..."
- "表X-Y列出了..."
- "...（参见图X-Y）"
- "对比图X-Y(a)与(b)可以发现..."
